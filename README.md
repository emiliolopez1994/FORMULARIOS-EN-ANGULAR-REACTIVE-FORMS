## Descripción

Este proyecto forma parte de las prácticas realizadas
en la asignatura de Lenguaje de Programación III,
enfocadas en el manejo de formularios reactivos
mediante Angular.

El objetivo de esta práctica es aplicar los conocimientos
adquiridos sobre la gestión de formularios, validación
de datos y manejo de componentes, utilizando TypeScript
y las herramientas que proporciona Angular.

## Objetivos de la práctica

- Implementar formularios mediante Reactive Forms.
- Trabajar con FormGroup, FormControl y Validators.
- Aplicar validaciones en los campos del formulario.
- Gestionar los datos ingresados por el usuario.
- Mostrar mensajes de validación.
- Organizar el código mediante componentes.
- Aplicar buenas prácticas de desarrollo frontend.

## Instalación y ejecución

Para ejecutar el proyecto localmente, es necesario
contar con Node.js y npm instalados.

Instalar las dependencias:

```bash
npm install
```

Iniciar el servidor de desarrollo:

```bash
npm start
```

Acceder desde el navegador:

http://localhost:4200

## Compilación del proyecto

```bash
npm run build
```

Esta práctica permite reforzar los conocimientos sobre
